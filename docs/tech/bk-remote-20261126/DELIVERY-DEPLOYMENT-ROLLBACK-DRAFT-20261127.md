## 5. 设备登记、撤销与恢复的操作语义

完整契约见 D:\demo2\bk-remote-account\BK-REMOTE-DEVICE-ENROLLMENT-20261127.md。

登记在同一有效登录会话中依次创建一次性部署令牌、获取随机挑战、提交原生私钥签名。客户端核对用途、账号受众、会话和令牌摘要、本机编号/标识/公钥、恢复旧编号、挑战、随机数及有效期后签原始字节；服务端完成前再次核对可信原生映射并事务消费令牌。旧的不安全登记接口继续关闭。

| 操作 | 账号侧结果 | 原生远控及现场结果 |
|---|---|---|
| 撤销账号访问 | 撤销清单授权、已证明设备会话、待登记令牌及授权；保留所有权历史 | 不自动改变目标固定密码，不代表停止目标服务或远端清理成功 |
| 解除归属 | 先原子撤销账号访问，再保留历史并标记已释放 | 后续认领仍须证明释放时原标识/公钥和原私钥；不等于公开设备密码 |
| 重装恢复 | 仅仍持有有效或已撤销但未释放归属的原所有者，使用新会话及当前原生私钥证明，明确选择旧编号 | 不能自动抢占；已释放历史不能继续授权旧所有者换新钥恢复 |
| 轮换固定密码或停用原生接收 | 需要目标设备真实执行和确认 | 与账号撤销分别记录，离线时标为待现场确认，不伪报完成 |

需要重装换钥再转交设备时，原所有者先完成明确恢复，再解除归属。清单可见性、签名登记在线状态、账号心跳、屏幕捕获与输入授权是不同事实；在线不表示可远控，未知也不应伪报为已离线或已撤销。
